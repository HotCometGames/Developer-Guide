# Developer Handbook

> A personal engineering reference manual for software developers.

---

## What Is This?

This is a comprehensive developer handbook covering everything from terminal basics to software architecture, game development, and AI-assisted coding. It is designed to be the **first place you look** when you forget a command, need a refresher on a concept, or want to understand best practices.

## How to Use This Handbook

### Finding What You Need

1. **By topic** - Browse the sections below
2. **By search** - Use your editor's search (Ctrl+Shift+F in VS Code)
3. **By cheat sheets** - Quick references for common commands

### Navigation

Each section has:
- A **README.md** with an overview and page index
- Individual **topic pages** with deep dives
- **Cheat sheets** for quick reference
- **Cross-links** to related topics in other sections
