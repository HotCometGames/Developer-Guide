## MVP Scope Management

### Must Have vs Nice to Have

| Category | Example |
|----------|---------|
| Must Have | Core feature that makes it work |
| Should Have | Important but not critical |
| Nice to Have | Polish, extras |
| Won't Have | Out of scope |

### The One-Thing Rule

Ask: "What is the ONE thing this project must do to be successful?"

- Focus 80% of time on that one thing
- Cut everything that doesn't serve it
- If it doesn't work, nothing else matters

### Scope Cutting Guide

| Phase | Time Left | Action |
|-------|-----------|--------|
| Start | 100% | Dream big |
| 75% | Cut features to realistic minimum |
| 50% | Cut to absolute MVP |
| 25% | Cut to core mechanic only |
| 10% | Fix bugs only, no new features |

## Pitch Structure

### 60-Second Pitch

| Time | Content |
|------|---------|
| 0-10s | Hook — "Have you ever..." |
| 10-25s | Problem — What pain point? |
| 25-40s | Solution — What did you build? |
| 40-50s | Demo — Show it working |
| 50-60s | Impact — Why it matters |

### Demo Tips

| Tip | Why |
|-----|-----|
| Practice the flow | Avoid fumbling live |
| Have a backup video | In case of demo failure |
| Show real data | More believable than "foo" |
| Keep it short | 2-3 minutes max |
| End with impact | What you'd do with more time |

## Timeboxing

| Activity | Timebox |
|----------|---------|
| Brainstorming | 30 min |
| Tech setup | 30 min |
| Core feature | 4-8 hours |
| Polish | 2-4 hours |
| Demo prep | 1-2 hours |
| Bug fixing | 1-2 hours max |

### When to Stop

- If a feature takes >2 hours, simplify or cut
- If blocked >30 min, switch tasks or ask for help
- If it's not done 1 hour before deadline, ship what you have

## Game Jam Specifics

### Game Feel Checklist

- [ ] Responsive controls (input → action < 100ms)
- [ ] Screen shake on impact
- [ ] Particle effects on actions
- [ ] Sound effects for all interactions
- [ ] Visual feedback for success/failure
- [ ] Smooth camera movement

### Common Game Jam Themes

| Theme | Twist |
|-------|-------|
| Growth | Literal or metaphorical |
| Connection | Multiplayer, networking, relationships |
| Time | Time loop, reverse, manipulation |
| Scale | Tiny to huge, perspective shift |
| Dual | Two modes, two characters, light/dark |

## Common Mistakes

| Mistake | Problem | Solution |
|---------|---------|----------|
| Over-scoping | Can't finish in time | Start with 1/3 of your idea |
| No MVP definition | Build random features | Define "done" before starting |
| Skipping sleep | Bad decisions, slow work | Sleep 6+ hours |
| Not demoing | Judges don't see your work | Always present, even if broken |
| Starting fresh setup | Wastes hours | Pre-setup environment |
| No version control | Lose work | Git init first, commit often |
| Working in isolation | Miss better ideas | Communicate with team |
